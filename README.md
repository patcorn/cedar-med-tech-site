# Cedar Med Tech — Interactive One-Page Site (Alternative 3)

- Starts with **one ring**
- **Swipe left/right** to decrease/increase the number of rings visible
- **Tap/click anywhere** to introduce a subtle distortion that affects all rings (based on tap location)
- Center logo remains visible beneath the rings

## Run locally
```bash
python -m http.server 8000
```
Open http://localhost:8000
